# B0(iii) — Phát hiện ghi ngoài `writes` (PHÁT HIỆN SAU) cho sóng goal

## Context

§1.3 (đã quyết): sóng song song bật mặc định + worker chung thư mục + `writes` chưa được kiểm → hai worker có thể ghi đè nhau mà Tester không biết. B0(iii) = sau mỗi wave, phát hiện file thay đổi ngoài tập `writes` đã khai và **báo cáo** (không chặn — nhãn PHÁT HIỆN SAU). Cơ chế: `git status --porcelain` trước/sau khi thư mục room là git repo; không phải repo → báo không audit được (đúng NOTE §3.2).

## Thiết kế (đã verify bằng khảo sát)

- **Điểm gắn**: vòng goal `server/group-goal-run.ts` — quanh thực thi batch wave (dòng ~497–508, `plan.writes` đã có sẵn trong scope qua `entries`), **chỉ path wave** (single-worker/solo bỏ qua v1 — không có `writes` khai để so).cwd room: `store.pinGroupCwd(groupId, threadId)` — mọi lane turn rơi vào cùng thư mục đã pin (invariant đã xác nhận).
- **Dep mới** trên `GoalRunDeps` (pattern `dispatchWave?`): `snapshotWrites?(): Promise<readonly string[] | undefined>` + `writesOutside?(before, declared): Promise<string[] | undefined>`. `undefined` = audit không khả dụng (không cwd / không git) → bỏ qua im lặng.
- **Module mới `server/writes-audit.ts`**:
  - `gitStatusPorcelain(cwd): Promise<string[] | undefined>` — `execFile("git", ["status", "--porcelain", "-z"], ...)` theo pattern `checkpoints.ts:209-227` (windowsHide, timeout, maxBuffer 16MB, xoá env `GIT_*` như `:186-189`), probe `git` khả dụng như `:142-148`; không git/ lỗi → `undefined`.
  - `writesOutside(before, after, declared): string[]` — **hàm thuần**: đường dẫn có dòng porcelain xuất hiện/đổi/trái mất giữa 2 snapshot, trừ tập `declared` (khớp sau chuẩn hoá: bỏ `./`, khớp đúng hoặc suffix hai chiều). Hạn chế ghi nhận: file **đã bẩn trước wave** mà bị sửa tiếp sẽ có cùng dòng porcelain → không báo được (hướng under-report, ghi vào limitations).
- **Báo cáo**: `deps.note(...)` — activity row `ok:false` từ coordinator: `<tên bot> changed files outside their declared writes: <5 đường dẫn đầu>`; batch sạch → không gì.
- **E2E `server/writes-audit.e2e.test.ts`** (POSIX-only — fake engine chạy `/bin/sh`): fixture worker có `FAKE_CLAUDE_TOOL_CALLS: [{Bash: printf stray > stray.txt}]` + `FAKE_CLAUDE_RUN_BASH=1` (chạy **thật** trong thư mục room — `drivers/claude.ts` spawn CLI với cwd = turn cwd); lead ra plan khai `writes:["page.tsx"]`; worker ghi `stray.txt` thật → room thread có activity row nhắc `stray.txt`, không nhắc `page.tsx`. Case sạch: worker chỉ ghi file đã khai → không row. Room tạo với `cwd` = thư mục có `git init`.
- **Unit `server/writes-audit.test.ts`**: parse/diff porcelain — file mới (untracked), modified, deleted, declared khớp suffix, file bẩn trước wave không báo (test có comment ghi hạn chế).
